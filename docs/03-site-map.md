## 2. 사이트맵 (가로 계층도)

실선(┬ ├ └)은 확정, `┄`로 표시한 항목은 점선(추후결정)입니다.

```
골라담냥 (데스크톱 PC 기준)
│
├── 홈 ─────────────────── 확정 · 핵심 페이지
│   ├── 첫 화면 ─────────── 사이트 소개 한 문장 · 박스 만들기 시작 버튼 (전체 폭 이미지 위 가운데 문구)
│   ├── 베스트 간식 박스 ── 베스트 박스 구성 미리보기 (둘러보기 역할, 좌우 번갈아 배치)
│   ├── 다른 집사들의 간식 세트 ─ 고양이 사진·종·나이·취향·구성품 (천천히 자동 슬라이드, 와이어프레임에서 추가)
│   ├── 정기배송 안내 ───── 매달 1회 고정 배송 흐름도 (가격 안내는 박스 만들기 옆 요약에서 표시)
│   └┄┄ 브랜드 소개 · 신뢰 정보 ┄┄ 추후결정 (이번 구성에서 제외)
│
├── 박스 만들기 ─────────── 확정 · 핵심 페이지 (가장 중요한 행동)
│   ├── 간식 선택 영역 ──── 둘러보기 · 선택 · 개수 조절
│   ├── 내 박스 영역 ────── 담긴 구성 확인 (고양이 도시락 칸에 간식이 담기는 방식)
│   ├── 내 박스 옆 요약 ─── 정기배송 방식·가격 안내 요약
│   ├┄┄ 다묘 가정 반영 방법 ┄┄ 추후결정 (반영은 확정, 방법 미정)
│   ├┄┄ 박스 개수 한도 ┄┄ 추후결정 (최소·최대 미정)
│   └┄┄ 담는 즉시 합계 금액 표시 ┄┄ 추후결정 (가격 정책 가정에 포함)
│
├── 정기배송 신청 ───────── 확정 · 핵심 페이지 (가장 중요한 행동)
│   ├── 구성 확인 ───────── 최종 박스 구성 확인
│   ├── 신청 입력 ───────── 신청 정보 입력
│   ├── 완료 안내 ───────── 신청 완료 확인
│   └┄┄ 입력 항목 · 회원가입/로그인 여부 ┄┄ 추후결정
│
┆
├┄┄ 정기배송 관리 ┄┄┄┄┄┄┄ 추후결정 (페이지 필요 여부 미정)
┆   └┄┄ 관리 기능 범위 ┄┄ 추후결정 (구성 변경·일시정지·해지 등)
┆
└┄┄ 공통 (전체) ┄┄┄┄┄┄┄┄┄ 추후결정 (페이지 외 미정·가정 항목)
    ├┄┄ 브랜드 비주얼 방향 ┄┄ 추후결정 (분위기·색감·캐릭터 사용 여부)
    ├┄┄ 가격 정책 ┄┄ 추후결정 (개당 가격·정기 할인·배송비, 01 문서의 가정)
    └┄┄ 간식 종류와 맛 구성 ┄┄ 추후결정 (6~8종, 01 문서의 가정)
```

> `공통 (전체)`는 특정 페이지에 속하지 않는 미정·가정 항목을 모아 보여주기 위한 묶음입니다. 페이지가 아닙니다.

## 3. 방문자 흐름 (확정)

**홈 → 박스 만들기 → 정기배송 신청 → 신청 완료**

- 가장 중요한 행동인 "박스 구성 후 정기배송 신청"이 3개 페이지 안에서 끝납니다.
- 단계는 홈에서 박스 만들기로, 박스 만들기에서 신청으로 가는 두 번입니다.
- Figma 사이트맵 아래쪽에도 같은 흐름을 그려두었습니다.

## 4. 페이지별 섹션 정리

### 4-1. 홈 (확정)

| 섹션 | 상태 | 내용 | 다음 행동 |
|---|---|---|---|
| 첫 화면 | 확정 | 사이트 소개 한 문장, 박스 만들기 시작 버튼 (전체 폭 이미지 위 가운데 문구, 와이어프레임 기준) | 박스 만들기로 이동 |
| 베스트 간식 박스 | 확정 | 베스트 박스 구성 미리보기 (홈이 둘러보기 역할, 박스 이미지와 구성품이 좌우 번갈아 나옴) | 박스 만들기로 이동 |
| 다른 집사들의 간식 세트 | 확정 (새 섹션) | 다른 사용자가 만든 세트를 고양이 사진·종·나이·취향·구성품으로 보여주고 천천히 자동 슬라이드 | 박스 만들기로 이동 |
| 정기배송 안내 | 확정 | 매달 1회 고정 배송 안내를 3단계 흐름도로 표시. 가격 안내는 박스 만들기 옆 요약에서 보여줌 (가격 정책은 추후결정) | 박스 만들기로 이동 |
| 브랜드 소개 · 신뢰 정보 | 추후결정 | 01 문서에 요구가 없어 이번 구성에서 제외 | - |

### 4-2. 박스 만들기 (확정)

| 섹션 | 상태 | 내용 | 다음 행동 |
|---|---|---|---|
| 간식 선택 영역 | 확정 | 간식 둘러보기, 선택, 개수 조절 (화면 왼쪽, 와이어프레임 기준) | - |
| 내 박스 영역 | 확정 | 담긴 구성 확인 (위에 고양이 귀가 달린 도시락 모양이고, 담은 간식 이미지가 곡선으로 날아가 칸에 하나씩 채워지는 방식). 화면 오른쪽에 고정되어 담는 동안 계속 보임 (와이어프레임 기준) | 정기배송 신청으로 이동 |
| 내 박스 옆 요약 | 확정 | 정기배송 안내 요약 (가격·배송 방식 재확인). 내 박스 아래, 같은 오른쪽 고정 영역 | 정기배송 신청으로 이동 |
| 다묘 가정 반영 방법 | 추후결정 | 반영한다는 것만 확정, 방법은 미정 | - |
| 박스 개수 한도 | 추후결정 | 최소·최대 한도 미정 (01 문서에서도 미정) | - |
| 담는 즉시 합계 금액 표시 | 추후결정 | 01 문서의 가정(가격 정책)에 포함된 내용 | - |

### 4-3. 정기배송 신청 (확정)

| 섹션 | 상태 | 내용 | 다음 행동 |
|---|---|---|---|
| 구성 확인 | 확정 | 최종 박스 구성 확인 | - |
| 신청 입력 | 확정 | 신청 정보 입력 | - |
| 완료 안내 | 확정 | 신청 완료 확인 | 완료 확인 |
| 입력 항목 · 회원가입/로그인 여부 | 추후결정 | 정해지지 않음 | - |

### 4-4. 정기배송 관리 (추후결정)

| 섹션 | 상태 | 내용 |
|---|---|---|
| 관리 기능 범위 | 추후결정 | 구성 변경, 일시정지, 해지 등. 범위가 정해진 뒤 페이지 필요 여부를 결정하며, 지금은 자리만 잡아둠 |

### 4-5. 공통 (추후결정)

| 항목 | 상태 | 내용 |
|---|---|---|
| 브랜드 비주얼 방향 | 추후결정 | 분위기, 색감, 캐릭터 사용 여부 (01 문서에서도 미정) |
| 가격 정책 | 추후결정 | 개당 가격, 정기배송 할인, 배송비. 01 문서의 가정이며 확정 아님 |
| 간식 종류와 맛 구성 | 추후결정 | 6~8종 구성. 01 문서의 가정이며 실제 종류는 정해지지 않음 |
