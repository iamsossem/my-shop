# 02. 골라담냥 (Golla Damnyang) 사이트 구조 (페이지 구성)

> 기준 문서: `01-site-purpose.md`
> 이 문서는 사이트 구현 전 단계에서 페이지 구성을 정리한 결과입니다.
> - **확정**: 사용자가 직접 선택하거나 01 문서에서 확정된 내용
> - **추후 결정**: 아직 정해지지 않았거나, 01 문서에서 가정으로만 남아 있는 내용 (2번에 따로 정리)
> - 이 문서에는 01 문서와 사용자의 선택에 없는 내용을 추가하지 않았습니다.

---

## 1. 확정 사항

### 1-1. 사용자가 확정한 선택

| 구분 | 선택 | 내용 |
|---|---|---|
| A | 박스 만들기 안에서 둘러보며 바로 담기 | 간식 둘러보기는 별도 페이지 없이 박스 만들기 안에서 둘러보며 바로 담는다. 홈의 간식 미리보기가 둘러보기 역할을 한다. |
| B | 홈 섹션 + 박스 만들기 옆 요약 | 정기배송·가격 안내는 별도 페이지 없이 홈 섹션과 박스 만들기 옆 요약으로 보여준다. |
| C | 구성 → 신청 페이지로 분리 | 박스 구성과 정기배송 신청을 별도 페이지로 나눈다. |

### 1-2. 페이지 구성 (확정)

핵심 페이지는 **홈, 박스 만들기, 정기배송 신청** 3개입니다.

| 페이지 | 방문자 행동 | 필요한 정보·기능 | 배치할 섹션 | 다음 행동 |
|---|---|---|---|---|
| **홈** | 어떤 사이트인지 이해한다 | 사이트 소개 한 문장, 박스 만들기 시작 버튼 | 첫 화면 | 박스 만들기로 이동 |
| **홈** | 간식을 훑어본다 (보조 행동) | 간식 종류·맛 미리보기 | 간식 미리보기 섹션 | 박스 만들기로 이동 |
| **홈** | 정기배송 방식·가격을 확인한다 (보조 행동) | 매달 1회 고정 배송 안내, 가격 안내 | 정기배송 안내 섹션 | 박스 만들기로 이동 |
| **박스 만들기** | 간식을 둘러보며 맛과 개수를 골라 담는다 (가장 중요한 행동) | 간식 선택, 개수 조절, 담긴 구성 확인, 다묘 가정 반영 | 간식 선택 영역 + 내 박스 영역 | 정기배송 신청으로 이동 |
| **박스 만들기** | 가격과 배송 방식을 다시 확인한다 (보조 행동) | 정기배송 안내 요약 | 내 박스 옆 요약 | 정기배송 신청으로 이동 |
| **정기배송 신청** | 구성을 확인하고 신청을 완료한다 (가장 중요한 행동) | 최종 구성 확인, 신청 입력 항목, 신청 완료 확인 | 구성 확인 + 신청 입력 + 완료 안내 | 완료 확인 |

### 1-3. 방문자 흐름 (확정)

**홈 → 박스 만들기 → 정기배송 신청 → 신청 완료**

- 가장 중요한 행동인 "박스 구성 후 정기배송 신청"이 3개 페이지 안에서 끝난다.
- 단계는 홈에서 박스 만들기로, 박스 만들기에서 신청으로 가는 두 번이다.

### 1-4. 01 문서에서 이어받은 확정 조건

- 정기배송 배송 주기는 매달 1회로 고정한다.
- 다묘 가정도 방문자 범위에 포함하고 박스 구성에 반영한다.
- 주 사용 기기는 데스크톱(PC)이며, 데스크톱 화면 기준으로 기획과 설계를 진행한다.

## 2. 추후 결정으로 남긴 사항

| 항목 | 관련 위치 | 현재 상태 |
|---|---|---|
| 신청 입력 항목, 회원가입이나 로그인 여부 | 정기배송 신청 | 정해지지 않음 |
| 박스 1개의 개수 한도(최소·최대) | 박스 만들기 | 정해지지 않음 (01 문서에서도 미정) |
| 다묘 가정을 박스 구성에 반영하는 방법 | 박스 만들기 | 반영한다는 것만 확정, 방법은 정해지지 않음 |
| 정기배송 관리 기능의 범위 | 정기배송 관리 | 미정 (01 문서에서도 미정) |
| 정기배송 관리 페이지의 필요 여부 | 정기배송 관리 | 기능 범위가 정해진 뒤 결정. 지금은 자리만 잡아둠 |
| 가격 정책 (개당 가격, 할인, 배송비) | 홈 정기배송 안내, 박스 만들기 옆 요약 | 01 문서의 가정이며 확정 아님 |
| 박스에 담는 즉시 합계 금액 표시 | 박스 만들기 옆 요약 | 01 문서의 가정(가격 정책)에 포함된 내용이며 확정 아님 |
| 간식 종류와 맛 구성 | 홈 간식 미리보기, 박스 만들기 | 01 문서의 가정이며 실제 종류는 정해지지 않음 |
| 홈의 브랜드 소개, 신뢰 정보 같은 섹션 | 홈 | 01 문서에 요구가 없어 이번 구성에서 제외 |
| 브랜드 비주얼 방향 | 전체 | 미정 (01 문서에서도 미정) |
