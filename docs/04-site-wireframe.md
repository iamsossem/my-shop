## 2. 표기 규칙 (Figma 범례와 동일)

| 표기 | 의미 |
|---|---|
| 회색 선 | 텍스트 (본문 문구는 선으로만 표시) |
| X 상자 | 이미지 |
| 실선 테두리 박스 | 버튼, 메뉴, 입력·선택·조절 요소 |
| **주황 굵은 테두리** | 핵심 행동 |
| 점선 | 추후결정 항목 |
| 굵은 검은 테두리 카드 | 담긴 상태의 간식 카드 (예시) |
| 흰 칸 / 연회색 + 칸 | 채워진 도시락 칸 / 빈 도시락 칸 (P02 S05) |
| 점선 곡선 + 점선 작은 사각형 | 담을 때 이미지가 날아가는 경로 (P02 S05) |
| 슬라이드 표시 (잘린 카드, 진행 점, "자동 슬라이드 →") | 자동으로 옆으로 천천히 넘어가는 목록 (P01 S11) |
| 아이콘 X + 선·화살표 | 단계 흐름도 (P01 S03) |
| 섹션 배경 면 (연한 면 / 흰 면) | P01 섹션 사이 배경색 구획. 색상값은 정하지 않음 (5-1) |
| 점선 가로선 (화살표 없음) | 화면 아래 끝 가이드 (P02, 1280×800 기준) |
| 한 방향 화살표 | 동작이 이어지는 방향 (P02 안: 담기 → 칸 채움 → 합계 갱신) |
| 검은 작은 태그 | ID (아래 3번) |

> 버튼·메뉴·개수 조절 요소 안의 글자(라벨)와 박스 이름표는 구분을 위해 실제 글자로 적었습니다.

## 7. 인터랙션

### 7-1. 박스 구성기 (P02)

P02의 S04 → S05 → S06이 이어지는 체험 요소(박스 구성기)입니다. S05를 위에 고양이 귀가 달린 도시락으로 만들고, S04에서 담은 간식 이미지가 곡선으로 날아가 칸에 하나씩 들어가는 방식은 이번에 정한 해석입니다(9번). 별도 담기 버튼은 없고 카드의 `+`가 담기입니다.

| 순서 | 사용자 행동 | 화면 변화 | 관련 ID |
|---|---|---|---|
| 1 | S04 카드에서 `+`(담기) 누름 | 카드의 개수가 1 늘고, 그 간식 이미지가 곡선으로 날아가 줄어들며 S05의 앞쪽 빈 칸 하나에 들어감 | C01~C06 → K01~K08 |
| 2 | S04 카드에서 `−` 누름 | 카드의 개수가 1 줄고, 그 간식으로 채워진 칸 하나가 비워짐 | C01~C06 → K01~K08 |
| 3 | S05에서 채워진 칸을 누름 | 그 칸이 비워지고, 해당 간식 카드의 개수가 1 줄어듦 | K01~K08 → C01~C06 |
| 4 | 칸이 채워지거나 비워짐 | 담긴 개수(예: 4 / 8)가 바뀌고, 합계 금액이 바로 바뀜 (합계는 추후결정) | L03, D03 |
| 5 | 칸이 모두 찬 상태 | 더 담을 수 없음. 칸 수가 곧 개수 한도이며 칸 수는 추후결정 | D02 |
| 6 | 구성을 마침 | 정기배송 신청으로 이동 | B04 → P03 |

| 정해지지 않은 것 | 이동 시간, 이미지 복사본 개수, 모션 줄이기 설정 사용자 처리, 모바일에서의 동작 |

### 7-3. P02 Figma 표시

- 예시 상태: 카드 1에 2개, 카드 2와 3에 1개씩 담겨 있고(C01 = 2, C02 = 1, C03 = 1), 세 카드는 굵은 검은 테두리와 "담김 n개"로 표시했습니다.
- S05의 K01~K04는 채워진 칸(이미지 X, 간식 이름, 1팩 표기), K05~K08은 빈 칸입니다. 도시락 위에는 고양이 귀를 달았고, 담기 모션의 이동 경로를 점선으로 그렸습니다(7-1-1).
- 화살표 두 개: S04 → S05 (가로, 담기 → 칸 채움), S05 → S06 (세로, 칸이 채워지면 합계가 바로 바뀜).
- 오른쪽 영역 안 순서는 위에서 아래로 S05(구성) → S06(요약·가격) → B04(단일 큰 버튼)이고, 버튼은 영역 폭 가득입니다(변경 C).
- S05·S06은 오른쪽 고정(sticky) 영역입니다. 카드 목록을 스크롤해도 따라오므로 담는 동안 칸과 합계가 한 화면(1280×800 기준) 안에 보입니다. Figma에는 화면 아래 끝(y=800)을 점선 가이드로 표시했습니다.
- S04의 카드는 2열 3행이라 세로가 깁니다. 카드 수가 늘면 왼쪽만 스크롤됩니다.

## 9. 와이어프레임에서 정한 내용 (문서에 없던 해석)

01·02·03 문서에 없는데 화면을 그리려면 필요해서 정한 부분입니다. 바꿔야 하면 알려주세요.

1. **상단 메뉴**: 문서에 메뉴 구성이 없어서 핵심 페이지 3개(홈, 박스 만들기, 정기배송 신청)와 로고로만 구성했습니다. 정기배송 관리(P04)는 필요 여부가 미정이라 메뉴에 넣지 않았습니다.
2. **P02 2단 배치**: 담는 동안 내 박스가 보여야 해서 P02만 위아래 쌓기를 하지 않았습니다. 왼쪽에 S04, 오른쪽에 S05(내 박스)와 그 아래 S06(요약)을 두었고, 오른쪽은 스크롤해도 따라오는 고정 영역입니다. 02 문서의 "내 박스 옆 요약"이 박스 옆에 있는 모양과 맞습니다. 나머지 페이지는 섹션을 위에서 아래로 쌓았습니다.
3. **간식 개수**: 홈 베스트 간식 박스는 예시 3개, 다른 집사의 간식 세트는 예시 4개, 박스 만들기 선택 카드는 6개를 그렸습니다. 01 문서의 가정(6~8종)이 확정되면 맞춥니다.
4. **개수 조절과 고양이 도시락**: 간식 선택과 개수 조절을 카드마다 `− n +` 하나로 묶었고 별도 담기 버튼은 두지 않았습니다(`+`가 담기). S05는 위에 고양이 귀가 달린 도시락으로 만들고 칸(K01~K08)을 두었습니다. 담기를 누르면 간식 이미지가 곡선으로 날아가 칸에 들어갑니다(Codrops 모션 참고, 7-1-1). 칸 하나는 간식 1팩이고, 칸 수 8개는 예시이며 개수 한도(D02)는 추후결정입니다.
5. **신청 완료**: 02 문서에서 완료 안내는 정기배송 신청 페이지의 섹션입니다. 그래서 별도 페이지 없이 P03의 S09로 그렸고, 신청 제출(B06) 뒤에 표시되는 것으로 표기했습니다.
6. **확인 버튼(B07)**: 02 문서는 "완료 확인"으로 흐름이 끝난다고만 해서 목적지를 정하지 않았습니다.
7. **구성 확인 목록(S07)**: 담긴 구성을 3행 예시로 그렸고, 수정 버튼은 문서에 없어서 두지 않았습니다.
8. **브랜드 소개·신뢰 정보 섹션**: 02 문서에서 이번 구성에서 제외한 항목이라 홈에 그리지 않았습니다.
9. **가격**: 가격 안내는 홈 S03에서 빼고 P02 S06의 안내 문구로만 보여줍니다(가격 정책은 추후결정이고 합계 금액 즉시 표시는 D03). 02 문서는 홈 정기배송 안내에 가격 안내를 포함하므로 이 부분이 달라졌습니다.
10. **P02 예시 상태**: P03 구성 확인(3종 4개)과 맞추려고 카드 1에서 2개, 카드 2와 3에서 1개씩 담아 K01~K04에 간식이 담긴 상태를 예시로 그렸습니다. 담긴 개수는 4 / 8로 표기했습니다.
11. **홈 S01**: 전체 폭 이미지 위에 가운데 문구를 얹는 구조로 그렸습니다. 02 문서는 사이트 소개 한 문장과 시작 버튼만 정했습니다.
12. **홈 S02 · S11**: S02는 "베스트 간식 박스"(박스 이미지와 구성품이 좌우 번갈아 나오는 목록)로, 02 문서의 "간식 미리보기" 역할을 이어갑니다. S11 "다른 집사들의 간식 세트"는 문서에 없던 새 섹션으로, 다른 사용자가 만든 세트를 고양이 사진·종·나이·취향·구성품으로 보여주고 천천히 자동 슬라이드합니다. 버튼 B08은 박스 만들기로 이동합니다. 세트 정보(종·나이·취향)가 실제 사용자 데이터인지 운영자가 고른 예시인지는 정해지지 않았습니다.
13. **홈 S03**: 글 목록 대신 3단계 흐름도(간식 고르기 → 수량 담고 신청 → 매달 1회 받아보기)로 그렸습니다. 02 문서의 "매달 1회 고정 배송 안내"를 그림으로 바꾼 것입니다.
14. **P02·P03 정리**: P01과 톤을 맞추려고 P02 제목과 안내를 문장형으로 다듬고 간식 이름(참치 스틱, 닭가슴살 트릿, 연어 큐브)을 P03과 같게 썼습니다. P03의 B06·B07은 P01처럼 오른쪽 아래에 두었습니다.
15. **P03 구성 확인(S07)**: 왼쪽에 우리 고양이가 간식을 맛있게 먹는 이미지(X 상자, 이미지 설명 포함), 오른쪽에 현재 담은 구성 목록(L04)을 두었습니다. 이 이미지가 방문자가 올린 고양이 사진인지 대표 이미지인지는 정해지지 않았습니다(입력 항목 D04와 함께 결정).

16. **완료 안내 팝업(S09)**: 신청 완료 안내는 별도 페이지가 아니라 P03에서 제출(B06) 뒤에 화면 위로 뜨는 팝업입니다. 뒤 화면은 어둡게 처리하고, 확인(B07)을 누르면 닫히는 것으로 정했습니다(02 문서는 완료 확인으로 흐름이 끝난다고만 함). 닫은 뒤 어디로 가는지는 정해지지 않았습니다. 팝업 프레임은 P03 오른쪽에 따로 그렸고 ID는 S09 그대로입니다.

17. **홈 섹션 배경 구획 (변경 B)**: 05 문서의 레퍼런스 분석에서 나온 변경입니다. 홈 섹션 사이를 배경 면의 전환(S02 연한 면 → S11 흰 면 → S03 연한 면)으로 나눕니다. 색상값은 정하지 않았습니다.
18. **오른쪽 영역 내부 순서와 단일 버튼 (변경 C)**: P02는 오른쪽 고정 영역을 구성(S05) → 요약·가격(S06) → 단일 큰 버튼(B04) 순서로 정리하고, 같은 목적지였던 B05를 B04로 합쳤습니다. P03은 S07 오른쪽을 구성 목록 → 요약·가격(추후결정) 순서로 두고, 큰 버튼 B06이 이 흐름의 끝에 오도록 명시했습니다. B06은 S08에 그대로 있습니다.
19. **홈 '더보기' 링크 (변경 D)**: S02 제목 오른쪽에 '더보기' 링크(B09)를 두고 P02로 연결합니다. 홈 중간에서도 박스 만들기를 시작할 수 있게 하려는 변경입니다.
