# 골라담냥

우리 냥이가 좋아하는 수제간식을 맛과 개수까지 직접 골라 담아 매달 받아보는 정기배송 박스 사이트의 디자인 시스템입니다. 지금 캔버스에 있는 P01 홈과 P02 박스 만들기 시안에서 실제로 쓴 값만 모았습니다. 데스크톱 1280px 기준이며, 모바일 규칙은 6단계(반응형)에서 추가합니다.

## 1. 디자인 원칙

- **쉽고 재미있게 고른다.** 귀여움은 도시락 모양, 파스텔 이미지 판, 둥근 모양으로 내고, 정보는 숫자로 짧고 분명하게 보여 줍니다.
- **쇼핑몰처럼 빽빽하지 않게.** 한 줄에 한 가지 정보만 둡니다. 이미지는 크게, 글자는 짧게 씁니다.
- **핵심 행동은 하나의 색으로.** 박스 만들기 시작(B01), 정기배송 신청으로 이동(B04), 정기배송 신청 완료(B06)만 보라색 `point`를 씁니다.

## 2. 말투

다정하고 발랄한 "~해요"체로 씁니다. 다만 개수·가격·배송 주기는 숫자로 짧게 말합니다.

| 상황 | 예시 |
| --- | --- |
| 안내 | 배송은 매달 1회로 고정돼요. 세 단계면 끝! |
| 행동 유도 | 맛을 고르고 +를 누르면 바로 담겨요. |
| 상태 | 무료배송까지 4,500원 남았어요. / 칸이 가득 찼어요. |
| 버튼 | 동사로 끝냅니다: 박스 만들기 시작, 정기배송 신청으로 이동 |

문서에 없는 가격, 기능, 후기는 쓰지 않습니다. 정해지지 않은 값은 `[미정]`으로 표시합니다.

## 3. 색

- **초록이 기본입니다.** 글자는 모두 `ink` 계열 한 가지(짙은 초록)로 통일하고, 회색이나 검정 글자는 쓰지 않습니다.
- **보라 `point`는 핵심 버튼 3개에만 씁니다.** 배지, 링크, 아이콘, 강조 글자에는 쓰지 않습니다.
- **배경 구획:** 홈은 `surface-hero`(S01) → `surface-tint`(S02) → `white`(S11) → `surface-tint`(S03) → `ink`(푸터) 순서로 띠를 바꿔 나눕니다. P02·P03은 `white` 바탕을 유지하고, 패널만 `surface-tint`를 씁니다.
- **파스텔(`pastel-*`)은 이미지 판 전용입니다.** 간식마다 색이 정해져 있습니다(`snack-*`). 글자 바탕으로는 쓰지 않습니다.
- **대비:** 본문 글자는 바탕과 4.5:1 이상입니다. `ink-label`(13~15px)은 흰 바탕 위에서만 씁니다.

| 간식 | 판 색 | 도형 색 |
| --- | --- | --- |
| 참치 스틱 | `pastel-coral` | `snack-tuna` |
| 닭가슴살 트릿 | `pastel-butter` | `snack-chicken` |
| 연어 큐브 | `pastel-peach` | `snack-salmon` |
| 북어 트릿 | `pastel-sand` | `snack-pollack` |
| 오리 져키 | `pastel-mocha` | `snack-duck` |
| 치킨 크런치 | `pastel-butter` | `snack-crunch` |

## 4. 글꼴

Pretendard 한 가지만 쓰고, 크기와 굵기로 위계를 나눕니다(가변 글꼴, OFL).

- **제목 3단계:** `display` 64/800 → `section-title` 36/800 → `card-title` 20~26/700
- **본문:** `body-lg` 18, `body` 16, `body-sm` 14, `caption` 13
- **제목 자간:** 큰 제목일수록 좁게 둡니다(-0.035em ~ -0.01em).
- **영문 라벨:** `eyebrow`만 대문자이고, 자간을 +0.04em 줍니다.
- **숫자:** 합계 금액은 `price-total`만 크게 씁니다.

## 5. 레이아웃과 간격

- **화면 폭:** 데스크톱 1280px, 좌우 여백은 `gutter` 80px, 콘텐츠 폭은 1120px입니다.
- **섹션 여백:** 위아래 `section-y` 112px로 넉넉하게 둡니다. 섹션 안 묶음 사이는 `space-8`~`space-12`(40~56px)입니다.
- **제목 줄:** 위에 `eyebrow`, 아래에 `section-title`을 두고, 오른쪽 끝에 보조 링크나 표시를 둡니다.
- **P02:** 좌우 2단(간식 카드 2열 + 오른쪽 400px 고정 영역)입니다. 오른쪽 영역은 위에서 아래로 내 박스 → 요약·가격 → 큰 버튼 순서로 쌓습니다.
- **배치:** 간격은 flex/grid의 `gap`으로 줍니다. 요소마다 margin을 따로 주지 않습니다.

## 6. 모양

- **모서리:** 버튼, 메뉴, 배지, 토글은 `radius-pill`(완전히 둥글게)입니다. 카드는 `radius-lg`(24px), 큰 이미지 카드는 `radius-xl`(28px), 도시락 칸은 `radius-sm`(10px)입니다.
- **그림자:** 평소에는 쓰지 않고 `line` 테두리만 씁니다. 마우스를 올렸을 때만 `shadow-card-hover`, `shadow-core-hover`를 씁니다.
- **선택 표시:** 고른 값만 `green-800`으로 채우고, 나머지는 외곽선만 둡니다(알약형 토글). 담긴 간식 카드는 `green-700` 2px 테두리로 표시합니다.

## 7. 이미지와 그래픽

- **이미지 배경:** 원형을 쓰지 않고 파스텔 단색 판에 이미지를 올립니다. P02 간식 카드는 이미지가 카드 가장자리까지 꽉 찹니다. (예외: S03 흐름도 단계 아이콘은 원형 판을 씁니다.)
- **고양이 귀 도시락:** 브랜드 모티프입니다. 로고, 홈 베스트 박스, P02 내 박스에 반복해서 씁니다. 칸 하나가 간식 1팩입니다.
- **아이콘:** 2~2.5px 선 아이콘을 쓰고, 색은 `ink` 또는 `green-800`입니다. 이모지는 쓰지 않습니다.
- **사진:** 실제 사진은 4단계(에셋 삽입)에서 넣습니다. 그 전까지는 일러스트로 자리를 표시합니다.

## 8. 움직임 (시안 기준)

- **hover:** 카드는 4px, 핵심 버튼은 2px 떠오릅니다(0.2~0.25초).
- **도시락 칸:** 마우스를 올리면 1.06배로 커지고, 누르면 그 칸이 비워집니다.
- **담기 모션:** 담기 모션, 슬라이더 속도, 모션 줄이기 처리는 5단계(인터랙션)에서 정합니다.

## 9. 아직 정하지 않은 것

- 30,000원 미만일 때 배송비
- 베스트 박스와 간식 세트의 실제 구성
- 고양이 종·나이·취향 데이터
- 모바일 규칙
- 실제 사진·로고 파일명
