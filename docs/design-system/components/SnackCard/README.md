# SnackCard

P02 S04에서 간식 하나를 보여 주고 바로 담게 하는 카드입니다. 2열 3행으로 배치합니다.

- **구조:** 이미지 영역(높이 220px, 카드 가장자리까지 꽉 참) → 정보 줄(왼쪽: 이름 `card-title` + 가격 `price` "/ 1팩", 오른쪽: Stepper)
- **이미지 바탕:** 간식별 `pastel-*` 단색을 씁니다(README 색 표 참고). 원형 배경은 쓰지 않습니다.
- **기본 상태:** `line` 2px 테두리, 모서리 `radius-lg`
- **담김 상태(개수 1 이상):** `green-700` 테두리, 이미지 왼쪽 위에 "n팩 담김" 배지
- **hover:** 4px 떠오르고 `shadow-card-hover`가 생깁니다.
- **담기 버튼:** 별도 담기 버튼은 두지 않습니다. `+`가 곧 담기입니다.
- **필요한 데이터:** 이름, 개당 가격, 이미지(4단계 전까지는 도형)
