# Button

버튼은 세 가지이고, 모두 알약형(`radius-pill`)입니다.

| 종류 | 쓰는 곳 | 모양 |
| --- | --- | --- |
| 핵심 (core) | B01 박스 만들기 시작, B04 정기배송 신청으로 이동, B06 정기배송 신청 완료 | `point` 채움, 흰 글자 `button-core`(20/800), 높이 64px, 오른쪽 화살표 |
| 보조 (sub) | B02·B03·B08 같은 섹션 끝 이동 버튼 | 흰 바탕, `green-800` 2px 테두리, `button`(17/700), 높이 52px |
| 링크 (more) | B09 더보기 | 글자 + 꺾쇠, `green-800`, 16/700 |

- 한 화면에 핵심 버튼은 하나만 둡니다.
- B04처럼 영역 폭을 채울 때는 `width:100%`로 늘립니다.
- **hover:** 핵심은 `point-hover`로 바뀌며 2px 떠오르고 `shadow-core-hover`가 생깁니다. 보조는 `green-800`으로 채워집니다.
- **포커스:** `green-800` 3px 윤곽선이 보이게 합니다.
- 페이지 이동은 `<a>`, 같은 화면 안 동작은 `<button>`으로 만듭니다.
