# StepFlow

홈 S03에서 정기배송 과정을 세 단계로 보여 주는 흐름도입니다.

- **단계:** 간식 고르기 → 수량 담고 신청 → 매달 1회 받아보기
- **단계 모양:** 168px 파스텔 원형 판(`pastel-mint` → `pastel-butter` → `pastel-peach`) 위에 `ink` 선 아이콘, 왼쪽 위에 `ink` 번호 배지(40px)
- **단계 아래:** 단계 이름 22/700, 설명 한 줄 16 `ink-muted`
- **단계 사이:** `arrow` 색 화살표
- **글자색:** 단계 색이 달라도 글자는 `ink` 한 가지로 통일합니다.
- **원형 판:** 이 흐름도만 원형 판을 씁니다. 다른 이미지 영역은 원형을 쓰지 않습니다.
