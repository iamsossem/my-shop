# PillToggle

여러 값 중 하나를 고르는 알약형 토글입니다. 고른 값만 진하게 채우고, 나머지는 외곽선만 둡니다.

- **쓰는 곳:** P02 내 박스의 고양이 수(1·2·3마리). 칸 수가 8, 16, 24로 바뀝니다.
- **모양:** 높이 44px, `green-800` 2px 테두리. 선택된 값은 `green-800`으로 채우고 흰 글자를 씁니다.
- **비활성(시안 기준):** 이미 담은 개수보다 칸이 적어지는 마리 수는 고를 수 없게 막습니다(투명도 0.4). 최종 처리 방식은 5단계에서 확정합니다.
- **다른 항목에 쓸지:** 아직 정하지 않았습니다([미정]).
- **접근성:** `role="radiogroup"` / `role="radio"` + `aria-checked`
