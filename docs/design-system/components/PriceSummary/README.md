# PriceSummary

P02 S06의 정기배송 방식·가격 요약입니다. 담는 즉시 금액이 바뀝니다.

- **순서:** 정책 문구 2줄(`green-800`, 15/600) → 구분선 → 상품 합계 / 정기배송 할인(5%) / 배송비 → 매달 결제 금액(`price-total` 28/800) → 도움말
- **할인:** 할인 금액은 "−" 기호와 함께 `green-800`으로 따로 한 줄에 표시합니다. 원가에 취소선을 긋지 않습니다.
- **배송비:** 30,000원 이상이면 "무료", 미만이면 [미정]입니다. 무료배송까지 남은 금액을 도움말로 안내합니다.
- **B04 핵심 버튼:** 요약 아래에 폭을 가득 채워 둡니다.
- **정책(01 문서):** 5% 할인, 30,000원 이상 무료배송, 매달 1회 고정 배송
