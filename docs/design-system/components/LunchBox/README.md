# LunchBox

고양이 귀가 달린 도시락 모양의 "내 박스"(P02 S05)입니다. 칸 하나가 간식 1팩입니다.

- **구조:** 제목 "내 박스" + 담긴 개수 "n / 칸 수" → 고양이 수 PillToggle → 도시락(`green-700` 몸체, `ear-pink` 귀 안쪽, `surface-inner` 안쪽 판) → 도움말 `caption`
- **칸 배열:** 1마리는 8칸(4열 2행, 칸 높이 52px), 2·3마리는 16·24칸(8열, 칸 높이 40px)입니다.
- **채워진 칸:** 그 간식의 `pastel-*` 바탕에 작은 `snack-*` 도형이 들어갑니다. 누르면 비워집니다.
- **빈 칸:** `green-300` 점선 테두리와 + 표시
- **채우는 순서:** 앞 칸부터 채웁니다. 칸이 다 차면 도움말이 "칸이 가득 찼어요."로 바뀝니다.
- **위치:** P02 오른쪽 고정(sticky) 영역의 맨 위에 둡니다.
- **담기 모션:** 간식이 날아와 칸에 들어가는 모션은 5단계에서 붙입니다.
