# NavBar

모든 페이지 맨 위에 같은 구성으로 두는 공통 메뉴입니다.

- **구성:** M01 로고(마크 + "골라담냥" + GOLLA DAMNYANG) | M02 홈 · M03 박스 만들기 · M04 정기배송 신청
- **크기:** 높이 80px, 아래에 `line` 1px 선
- **현재 페이지:** `surface-nav-active` 회색 알약 배경, 글자는 `ink` 700. `aria-current="page"`를 붙입니다.
- **다른 메뉴:** 글자는 `ink-muted` 600이고, 마우스를 올리면 같은 회색 알약이 깔립니다.
- **홈 첫 화면:** 홈에서는 메뉴가 S01 위에 반투명 흰 바탕(`#FFFFFF99`)으로 겹쳐 있습니다(사용자 시안).
- **모바일 메뉴:** 6단계에서 정합니다.
