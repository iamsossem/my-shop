# Stepper

간식 개수를 하나씩 더하고 빼는 `− n +` 조절기입니다.

- **모양:** `surface-stepper` 알약 바탕 위에 44px 흰 원형 버튼 2개, 가운데 숫자 18/800
- **`+`:** 1개를 담고, 내 박스의 앞쪽 빈 칸이 채워집니다. 칸이 모두 차면 비활성됩니다.
- **`−`:** 그 간식이 든 칸 하나를 비웁니다. 개수가 0이면 비활성됩니다.
- **hover:** 버튼이 `green-800`으로 채워지고 글자는 흰색이 됩니다.
- **비활성:** 투명도 0.35
- **접근성:** 각 버튼에 "[간식 이름] 담기/빼기" `aria-label`을 붙이고, 숫자에는 `aria-live`를 둡니다.
