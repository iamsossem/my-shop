# Logos

고양이 귀가 달린 도시락 마크입니다. 박스를 "골라 담는" 사이트의 핵심 동작을 담았습니다.

- **golla-mark.svg:** 기본 마크. 흰색·연한 바탕 위에 씁니다(`green-700` 몸체).
- **golla-mark-reverse.svg:** 반전 마크. `ink` 바탕(푸터) 위에 씁니다(`surface-hero` 몸체).
- **lunchbox-illustration.svg:** 홈 베스트 박스 같은 큰 박스 일러스트
- **함께 쓰기:** 마크 오른쪽에 "골라담냥" 24/800과 "GOLLA DAMNYANG" 11/600(자간 +0.08em)을 두 줄로 붙입니다. 마크와 글자 사이는 `space-3`입니다.
- 사용자가 최종 로고 파일을 준비하면 이 마크를 교체합니다(4단계).
