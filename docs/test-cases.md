**② 기본 환경과 시작 상태**
- 테스트 방법에 기기가 적혀 있지 않으면 PC 브라우저 창을 가로 1280, 세로 800 크기로 두고 마우스로 테스트한다.
- 모든 케이스는 **새로고침한 상태**에서 시작한다(PC: `F5` 키, 휴대폰·태블릿: 주소창의 새로고침 버튼). 새로고침하면 담아 둔 간식과 장바구니가 모두 비워진다.

**④ 북어 트릿 박스 만들기** (여러 케이스의 시작 조건)
1. 박스 만들기 페이지를 연다.
2. "북어 트릿" 카드의 `+`를 8번 누른다. "내 박스"가 "8 / 8칸"이 된다.
3. PC에서는 오른쪽 "장바구니 담기" 버튼을, 휴대폰·태블릿에서는 하단 바의 "담기"를 누른다.
4. 박스 2개가 필요하면 2~3을 한 번 더 한다. (박스 1개 금액은 16,000원)

**⑤ 키보드로만 조작하기**
- 마우스에서 손을 떼고 `Tab` 키를 누르면 선택 표시(테두리)가 다음 버튼·링크로 옮겨 간다. `Shift`+`Tab`은 이전으로 돌아간다.

**⑥ 모션 줄이기 설정 켜기**
- Windows 11: 설정 → 접근성 → 시각 효과 → "애니메이션 효과" 끄기
- Windows 10: 설정 → 접근성 → 디스플레이 → "Windows에서 애니메이션 표시" 끄기
- macOS: 시스템 설정 → 손쉬운 사용 → 디스플레이 → "동작 줄이기" 켜기
- 설정을 바꾼 뒤 브라우저에서 페이지를 새로고침한다. 테스트가 끝나면 원래대로 돌려 둔다.

**⑦ 크기 재기**
- **PC 창 폭:** 브라우저에서 `F12`로 개발자 도구를 연 채 창 오른쪽 끝을 끌어 줄이면 화면 오른쪽 위에 "가로 × 세로" 숫자가 잠깐 뜬다.
- **실제 기기의 버튼 크기:** 기기를 PC에 USB로 연결해 PC 개발자 도구로 본다.
  - 안드로이드: 기기에서 USB 디버깅을 켜고, PC 크롬 주소창에 `chrome://inspect` 입력 → 해당 탭의 "inspect"
  - 아이폰·아이패드: 기기 설정 → Safari → 고급 → "웹 속성" 켜고, 맥 Safari "개발자용" 메뉴에서 기기 선택
  - 개발자 도구 왼쪽 위 화살표 아이콘을 누르고 버튼에 갖다 대면 "가로 × 세로" 크기가 보인다.
