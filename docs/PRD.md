## 1. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 목적 | 매달 간식을 사는 집사가 맛과 개수를 쉽고 재미있게 골라 박스를 만들고, 번거롭지 않게 정기배송 신청까지 마치도록 돕는다. 가상 사이트이며 실제 결제·저장은 하지 않는다. |
| 방문자가 원하는 것 | ① 맛·개수를 내 마음대로 고르기 ② 매달 번거롭지 않은 정기배송 관리 (주요 방문자: 매달 간식을 사는 집사, 다묘 가정 포함) |
| 핵심 행동 | 박스를 구성하고 정기배송 신청까지 완료하기 (P01 홈 → P02 박스 만들기 → P04 장바구니 → P03 정기배송 신청 → S09 신청 완료 팝업) |

## 2. 요구사항 표

- 순서: 공통 → P01 → P02 → P04 → P03 → 전체 페이지 (방문자 흐름 순서)
- 우선순위 기준: **상** = 안 되면 핵심 행동(박스 구성 → 정기배송 신청 완료)을 못 한다
- 화면 ID는 지금 만들어진 사이트 기준이다: P01 홈(`/`), P02 박스 만들기(`/box`), P04 장바구니(`/cart`), P03 정기배송 신청(`/subscribe`)
- 휴대폰 기준은 터치 기기 `max-width: 767px` 구간이다
- 장바구니 안의 영역에는 따로 ID를 두지 않고 `P04`로만 표기한다
- 접근성 기준은 PROJECT_CONTEXT.md에 정해진 4가지와 S11 자동 슬라이드 멈춤을 따른다: 모션 줄이기 설정 처리(R-19), S02 구성품 키보드 포커스(R-03), 터치 기기 누르는 영역 44px(R-18), 입력칸 위 글자 커서(R-16), S11 키보드 포커스·모션 줄이기 시 자동 넘김 멈춤(R-04·R-19)

## 3. 미정·제외 항목

### 3-1. 제외 (이번 제작에서 만들지 않음)
- 정기배송 관리 페이지 (구성 변경·일시정지·해지). 메뉴에도 넣지 않는다. 와이어프레임에서는 P04였지만, 지금 만들어진 사이트에서 P04는 장바구니(`/cart`)다.
- 홈 브랜드 소개·신뢰 정보 섹션
- 회원가입·로그인, 실제 결제, 서버 저장
- 고양이 수 선택·추가 (여러 박스가 필요하면 장바구니에 박스를 여러 개 담음)
- 입력 칸 형식 검사 (F01~F03은 비어 있는지만 확인)
- 성능 기준 (페이지 로딩 시간 등)
- 성과 지표 (신청 전환율·이탈률 등 측정·분석 항목)
- 지원 브라우저 범위 (View Transitions 미지원 브라우저는 모션 없이 바로 이동한다는 것만 정해짐)

### 3-2. 미정 (PROJECT_CONTEXT.md에 정해진 내용 없음)
- 없음
