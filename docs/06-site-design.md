  - 디자인 시스템 "골라담냥 디자인 시스템": https://claude.ai/artifact/PtWNmUrRwZ4SdDnhFq6Jkq

## 1. 디자인 원칙

1. **쉽고 재미있게 고른다.** 귀여움은 고양이 귀 도시락 모양, 파스텔 이미지 판, 둥근 모양으로 냅니다. 개수·가격·배송 주기는 숫자로 짧고 분명하게 보여 줍니다.
2. **쇼핑몰처럼 빽빽하지 않게.** 한 줄에 한 가지 정보만 두고, 이미지는 크게, 글자는 짧게 씁니다. 여백은 넉넉하게 둡니다.
3. **핵심 행동은 하나의 색으로.** B01·B04·B06만 보라색 `point`를 씁니다.

## 2. 말투

- **한 줄 설명:** 다정하고 발랄한 "~해요"체로 말하되, 개수·가격·배송 주기는 숫자로 짧게 말합니다.
- **예시 문장:** "배송은 매달 1회로 고정돼요. 세 단계면 끝!"

| 상황 | 예시 |
| --- | --- |
| 첫 화면 제목 | 맛도 개수도, 직접 골라 담아요 |
| 첫 화면 설명 | 골라담냥은 우리 냥이가 좋아하는 수제간식을 맛과 개수까지 직접 골라 담아 매달 받아보는 정기배송 박스 사이트예요. (01 확정 소개 문장) |
| 행동 유도 | 맛을 고르고 +를 누르면 바로 담겨요. |
| 상태 안내 | 무료배송까지 4,500원 남았어요. / 칸이 가득 찼어요. |
| 버튼 | 동사로 끝냅니다: 박스 만들기 시작, 정기배송 신청으로 이동 |

문서에 없는 가격, 기능, 후기는 쓰지 않습니다. 정해지지 않은 값은 `[미정]`으로 표시합니다.

## 3. 컬러

### 3-1. 사용 규칙

- **초록이 기본입니다.** 글자는 모두 짙은 초록(`ink` 계열) 한 가지로 통일합니다. 회색이나 검정 글자는 쓰지 않습니다.
- **보라 `point`는 핵심 버튼 B01·B04·B06에만 씁니다.** 배지, 링크, 아이콘, 강조 글자에는 쓰지 않습니다.
- **파스텔은 이미지 판 전용입니다.** 글자 바탕으로는 쓰지 않습니다.
- **대비:** 본문 글자는 바탕과 4.5:1 이상입니다.

## 5. 레이아웃과 간격

- **화면 폭:** 가로 1280px, 좌우 여백 `gutter` 80px, 콘텐츠 폭 1120px
- **밀도:** 낮게 둡니다. 섹션 위아래 여백은 `section-y` 112px입니다.
- **간격 주는 법:** 간격은 flex/grid의 `gap`으로 줍니다.

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `space-1` | 4px | 개수 조절 버튼 사이 |

### 정보 묶음 원칙

- **섹션 제목 줄:** 위에 `eyebrow`, 아래에 `section-title`을 두고, 오른쪽 끝에 보조 링크나 표시를 둡니다.
- **홈 배경:** 띠를 바꿔 구획합니다. S01 `surface-hero` → S02 `surface-tint` → S11 `white` → S03 `surface-tint` → 푸터 `ink`
- **P02·P03:** `white` 바탕을 유지하고, 패널만 `surface-tint`를 씁니다.
- **P02:** 왼쪽 간식 카드 2열 3행, 오른쪽 400px 고정(sticky) 영역입니다. 오른쪽은 위에서 아래로 내 박스 → 요약·가격 → B04 순서입니다.

## 7. 이미지와 로고

- **이미지 배경:** 원형 배경 없이 파스텔 단색 판에 이미지를 올립니다(사용자 수정 반영). 한 화면에서 이미지 배경 처리는 이 한 가지만 씁니다. S03 흐름도 아이콘만 원형 판을 씁니다.
- **P02 간식 카드:** 이미지가 카드 가장자리까지 꽉 찹니다(사용자 수정 반영).
- **브랜드 모티프:** 고양이 귀 도시락입니다. 로고, 홈 베스트 박스, P02 내 박스에 반복해서 씁니다.
- **로고(임시 제안):**
  - 도시락 마크 + "골라담냥"(24/800) + "GOLLA DAMNYANG"(11/600, 자간 +0.08em)
  - 기본 마크와 푸터용 반전 마크가 디자인 시스템 Logos에 있습니다.
  - 최종 로고는 사용자가 준비해 4단계에서 교체합니다.
- **아이콘:** 2~2.5px 선 아이콘, 색은 `ink` 또는 `green-800`. 이모지는 쓰지 않습니다.
- **사진:** 실제 사진은 4단계에서 넣습니다. 그 전까지는 일러스트나 도형으로 자리를 표시합니다.

- 정기배송 할인 표시 방식 (시안: 할인 금액을 "−"로 따로 한 줄에 표시, 확정 전)
- 고양이 수를 줄일 때 처리 (시안: 담은 개수보다 칸이 적어지는 마리 수는 선택 막음, 확정 전)
- 베스트 박스·간식 세트의 실제 구성, 고양이 종·나이·취향 데이터
- 실제 로고·사진 파일명 (4단계)
- 모바일 헤더·배치·터치 동작 (6단계)
